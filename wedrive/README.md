# WeDrive multi-region runtime

Форк **рантайма** Valhalla: один `GraphReader` держит несколько независимо собранных графов,
а `Thor` ведёт по ним ОДИН поиск, пересекая границы через внешнюю таблицу порталов.

Формат `.gph` не тронут. Mjolnir не тронут. Тайлы стоковые, их читает и стоковая Valhalla.

## Зачем

Карта-фабрика WeDrive может дать маршрут через границу только если собрать все страны **одним
проходом**. Это значит: обновление одной страны требует пересборки всех, вся Европа обязана быть
одного возраста, и нет гарантии, что старая и новая сборки сойдутся. Если рантайм умеет держать
несколько графов — страны становятся независимыми артефактами, и монолитная сборка Европы больше
не нужна.

## Что доказано

Подробности и цифры — в [`results/THOR-PROGRESS.md`](results/THOR-PROGRESS.md) и
[`results/RESULTS.md`](results/RESULTS.md).

| | |
|---|---|
| stock-маршрут после патчей | **идентичен** upstream 3.6.3: 109.300 км / 5613.3 с / 26 манёвров |
| два графа без порталов | **NO ROUTE** — поиск честно исчерпывается |
| Кишинёв → Яссы через портал | 160.682 км, **1** смена региона |
| Яссы → Кишинёв (обратное) | 161.239 км, **1** смена региона |
| Молдова, разрезанная пополам и собранная двумя независимыми сборками | **279.59 км** против **279.932 км** у цельного графа |
| непрерывность геометрии на переходе | разрыв **0 м** |
| потерь региона во всех прогонах | **0** |

## Устройство

```
на диске          GraphId = 46 бит, как его пишет Mjolnir
в GraphReader     GraphId = region | 46 бит        <- регион только в памяти
в EdgeLabel       edgeid_ 46 | endnode_ 46 | region_ 3
```

Инвариант, на котором всё держится:

```
region ОБЯЗАТЕЛЕН   там, где по GraphId выбирается тайл
region НЕ НУЖЕН     для индексации внутри уже выбранного тайла
region ЧУЖОЙ        всегда ошибка
менять region       вправе ТОЛЬКО портал
```

Портал — внешняя запись, а не ребро внутри тайла:

```cpp
struct WeDrivePortal { GraphId to; float distance; };
```

## Как собрать

```bash
./dev-container.sh              # контейнер с исходниками Valhalla
./apply-patches.sh /src/valhalla
make -C /src/valhalla/build -j && make -C /src/valhalla/build install
```

Патчи идемпотентны и проверяют каждый свой кусок по уникальному маркеру; порядок задан номерами.

## Проверки

| скрипт | что проверяет |
|---|---|
| `tools/run_gid.sh` | инвариант `GraphId` — 19 утверждений |
| `tools/regress.sh` | патченная сборка против stock upstream 3.6.3 |
| `tools/final.sh` | вся матрица multi-region через настоящий Thor |
| `tools/run_cut.sh` | production-таблица порталов по линии разреза |
| `verify-from-clone.sh` | **всё сразу, из чистого клона** — откат дерева к стоку, патчи, идемпотентность, сборка, все тесты |

Последний и есть ответ на вопрос «а соберётся ли это у кого-то кроме автора»: он доказывает
`git clone -> скрипты из репозитория -> сборка -> тесты`, не используя ничего с машины
разработчика. Прогон на чистом клоне `be4fc3e`: все восемь пунктов OK.

## Что НЕ сделано

* **Loki про регионы не знает** — кандидаты в стенде строятся вручную, поэтому полный
  `valhalla_service` с двумя регионами пока невозможен. Это следующая задача.
* Odin/narrative через границу не проверялся.
* Портал стоит ноль; настоящий погранпереход стоит не ноль.
* Регион занимает 3 бита = 7 регионов. Для Европы мало.
* Android `libvalhalla-wrapper.so` не собирался.
